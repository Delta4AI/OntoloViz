# OntoloViz Web (V2)

Browser-based ontology visualization. The successor to the deleted Dash port.

## Stack

- Vite + React 18 + TypeScript (strict)
- D3 (`d3-hierarchy`, `d3-scale`, `d3-shape`) for layout math
- Canvas 2D for rendering (WebGL only if profiling demands it)
- Tailwind for styling
- Zustand for state
- papaparse + SheetJS for file parsing
- Vitest for tests

## Quickstart

```bash
cd web
pnpm install
pnpm dev          # http://localhost:5173 — proxies /api to FastAPI on :8000
```

Start the backend separately (see `../server/README.md`) or use `make dev` at
the repo root to run both concurrently.

## Parity vs the Python reference

Propagation behavior is verified against `src/ontoloviz/core.py` through JSON
fixtures generated by a Python harness:

```bash
make parity-fixtures        # regenerate web/tests/fixtures/parity/*.json
make test-web               # TS pipeline (parse + propagate) must match
```

The harness uses **bottom-up traversal** (level-descending) so propagation is
transitive. The legacy `core.py` MeSH path iterates in dict-insertion order
and propagates only one level per pass — the V2 port intentionally fixes
this. See the docstring in `tests/parity/generate_fixtures.py` for the full
rationale.

## Roadmap

The scaffold is intentionally bare. Subsequent phases:

1. ✅ TSV parsing + data model
2. ✅ Count propagation in TS (parity-tested against `core.py`)
3. Color propagation + scale builder (next)
4. Single-tree renderer (D3 partition + Canvas) with zoom + breadcrumbs
5. Settings panel
6. Virtualized summary grid with linked hover/search
7. Exports: high-DPI PNG, SVG, self-contained interactive HTML
8. Backend OBO loader + future model API integration
